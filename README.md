## Overview

This repository contains my **capstone project** for the Google Data Analytics course. The focus is on analyzing **Fitbit tracker data** to support a **marketing strategy for Bellabeat Global’s Spring product**, using step counts and MET (Metabolic Equivalent of Task) values to measure physical activity.

## About

Bellabeat uses the Spring water bottle product to track hydration and daily activity. This project analyzes how users engage with their smart devices to provide actionable insights for marketing and product strategy.

Key highlights:

* **Data & Tools:** Fitbit tracker data, Google Sheets, R (tidyverse, ggplot2, lubridate, janitor), Google BigQuery.
* **Analysis Goals:**

  * Track daily activity levels and METs values.
  * Identify patterns by day, week, and around special events (e.g., Women’s Day).
  * Summarize activity trends to inform marketing strategy.
* **Outputs:** Cleaned datasets, visualizations, and recommendations for Bellabeat’s Spring product marketing.
